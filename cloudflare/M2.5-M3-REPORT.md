## B. M3 — AI Publishing API

### B.1 Đã triển khai

Prefix `/api/v1` (giữ contract Node):
- `GET /health`, `GET /openapi.yaml`, `GET /me`.
- `GET /categories`, `/tags`.
- `GET /posts` (status/category/q/limit/offset), `/posts/:id`, `/posts/slug/:slug`.
- `POST /posts` (scopes, idempotency, external_id, review demotion, sanitize).
- `PATCH /posts/:id`.
- `POST /posts/:id/publish`, `/schedule`, `/unpublish`; `DELETE /posts/:id`.
- `POST /media` → **501** vì R2 chưa cấp phép.
- Bearer API key, scopes `posts:read/write/publish`, rate limit theo client + IP, WWW-Authenticate, `X-RateLimit-*`.
- Idempotency replay/conflict; external_id replay; review mode demote `published/scheduled` → `review`; auto mode + publish scope.
- Content cap **32 KB** (413 `payload_too_large`) để bảo vệ CPU Free; đây là giới hạn staging cần được phê duyệt cho production.
- Sanitize Markdown/HTML trong DO; audit API actions; soft delete 410.
